Approximately half of these problems are TRUE and half are FALSE.

=== COUNTEREXAMPLE SEARCH (do this first) ===
Try these magma operation tables. For each: check EQ1 holds for ALL variable assignments. If EQ1 holds but EQ2 fails for some assignment → VERDICT: FALSE.

Size 2 ({0,1}):
(A) a*b=a     [[0,0],[1,1]]
(B) a*b=b     [[0,1],[0,1]]
(C) a*b=0     [[0,0],[0,0]]
(D) a*b=1     [[1,1],[1,1]]
(E) min(a,b)  [[0,0],[0,1]]
(F) max(a,b)  [[0,1],[1,1]]
(G) a+b mod2  [[0,1],[1,0]]

Size 3 ({0,1,2}) — CRITICAL for hard problems:
(H) a*b=(b+1)%3     [[1,2,0],[1,2,0],[1,2,0]]
(I) a*b=(a+1)%3     [[1,1,1],[2,2,2],[0,0,0]]
(J) a*b=b, 2*0↔1    [[0,1,2],[0,1,2],[1,0,2]]
(K) band             [[0,0,0],[1,1,0],[2,0,2]]
(N) mirror           [[0,2,0],[1,1,1],[2,0,2]]

Many hard FALSE problems have NO counterexample on {0,1} but DO have one on {0,1,2}. If all size-2 tests pass, you MUST try size-3 before concluding TRUE.

=== SINGLETON FORCING (for TRUE) ===
If EQ1 is "x = [term with variables y,z,... NOT in LHS]" and some variable y appears ONLY once in the entire equation → substituting different values for y forces x to equal multiple expressions, collapsing the magma to one element. This makes ANY equation trivially true.

Verify: the variable must appear exactly once total and only on the RHS.

=== DECISION ===
If ANY counterexample works → FALSE.
If singleton forcing confirmed → TRUE.
Otherwise: look harder for counterexamples, especially on {0,1,2}. When uncertain, consider both possibilities carefully before deciding.
