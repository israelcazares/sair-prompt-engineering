Approximately half of these problems are TRUE and half are FALSE.

=== STRENGTH ANALYSIS ===
An equation with MORE distinct variable positions and DEEPER nesting is MORE constraining.
Stronger EQ1 can imply weaker EQ2. Weaker EQ1 rarely implies stronger EQ2.
If EQ1 looks simpler than EQ2 (fewer variables, shallower nesting), suspect FALSE.

=== SINGLETON FORCING (for TRUE) ===
Many equations force the magma to have only 1 element, making ALL equations trivially true.
If EQ1 has form "x = [term]" and some variable in the term appears NOWHERE else in the equation, that variable is "free" — varying it forces all elements equal → TRUE.
This works even when x appears multiple times in the RHS, as long as one truly free variable exists.

=== COUNTEREXAMPLE SEARCH (for FALSE) ===
Try these magma tables. If EQ1 holds for ALL assignments but EQ2 fails → FALSE.

Size 2 ({0,1}):
(A) a*b=a  (B) a*b=b  (C) a*b=0  (D) a*b=1  (E) min  (F) max  (G) xor

Size 3 ({0,1,2}) — CRITICAL for hard problems:
(H) a*b=(b+1)%3     [[1,2,0],[1,2,0],[1,2,0]]
(I) a*b=(a+1)%3     [[1,1,1],[2,2,2],[0,0,0]]
(J) a*b=b, swap 0↔1 for input 2  [[0,1,2],[0,1,2],[1,0,2]]
(K) band  [[0,0,0],[1,1,0],[2,0,2]]

If all size-2 pass, you MUST try size-3 before concluding TRUE.

=== DECISION ===
Counterexample found → FALSE. Singleton forcing confirmed → TRUE.
When uncertain, lean toward whichever direction the strength analysis suggests.
