Approximately half of these problems are TRUE and half are FALSE.

=== PHASE 1: COUNTEREXAMPLE SEARCH (always do first) ===
Try these magma tables. For each: check EQ1 holds for ALL assignments. If EQ1 holds but EQ2 fails → VERDICT: FALSE. Stop.

Size 2 ({0,1}):
(A) a*b=a     [[0,0],[1,1]]
(B) a*b=b     [[0,1],[0,1]]
(C) a*b=0     [[0,0],[0,0]]
(D) a*b=1     [[1,1],[1,1]]
(E) min(a,b)  [[0,0],[0,1]]
(F) max(a,b)  [[0,1],[1,1]]
(G) a+b mod2  [[0,1],[1,0]]

Size 3 ({0,1,2}) — CRITICAL for hard problems:
(H) a*b=(b+1)%3     [[1,2,0],[1,2,0],[1,2,0]]
(I) a*b=(a+1)%3     [[1,1,1],[2,2,2],[0,0,0]]
(J) a*b=b, 2*0↔1    [[0,1,2],[0,1,2],[1,0,2]]
(K) band             [[0,0,0],[1,1,0],[2,0,2]]
(N) mirror           [[0,2,0],[1,1,1],[2,0,2]]

Check ALL of A through N systematically. Many hard FALSE problems have NO size-2 counterexample but DO have one on size 3.

If ANY counterexample verified → VERDICT: FALSE. Stop.

=== PHASE 2: STRUCTURE CHECK (determines reasoning mode) ===
Analyze EQ1's structure. Check these conditions IN ORDER:

BLOCK 1 — SELF-REFERENTIAL:
  Count occurrences of x in the RHS of EQ1.
  If x appears ≥2 times in RHS → BLOCKED.

BLOCK 2 — NO FREE VARIABLES:
  If ALL variables appear on BOTH sides of EQ1 → BLOCKED.

BLOCK 3 — REPEATED VARIABLE IN LHS:
  If any variable appears more than once in EQ1's left side → BLOCKED.

=== PHASE 3: DECISION (depends on structure) ===

*** IF ANY BLOCK FIRED → HARD MODE ***
The equation has adversarial structure. S2 is unreliable here.
Only accept TRUE if S1 applies:
  S1: LHS is a single variable x AND x does NOT appear anywhere in RHS.
  If S1 → TRUE. Otherwise → FALSE.

*** IF NO BLOCK FIRED → STANDARD MODE ***
The equation has tractable structure. Apply singleton forcing:
  S1: LHS is a single variable x, and x absent from RHS → TRUE.
  S2: A variable appears exactly once in the entire equation, on one side only → singleton forced → TRUE.
If singleton forcing confirmed → TRUE.
If NONE of A–N provided a counterexample and no singleton found:
  the implication is very likely TRUE.
  Only override by constructing a custom magma with full verification.
